# Icons

The `<Icon>` component renders icons from `@clidey/ux/icons`. Icons inherit the text color unless you set `color`. Names use kebab-case.

## Basic Usage

<Specimen label="&lt;Icon&gt;">

```mdx
<Icon icon="promote" />
<Icon icon="code" />
<Icon icon="check-circle" />
```

</Specimen>

## Icon Catalog

The catalog includes every icon published by Clidey Design, including distinct variants with `-alt` suffixes. Click an icon to copy its MDX tag. Existing source-prefixed names such as `enterprise/chevron-down` continue to work.

## Props Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `icon` | `string` | — | Clidey Design icon name, such as `check-circle`. |
| `color` | `string` | Inherits from text | CSS color value. |
| `size` | `number` | `24` | Icon size in pixels. |
| `className` | `string` | — | Additional CSS classes. |
