# Code Blocks

Dory provides rich code block components with syntax highlighting, tab groups, and interactive copy functionality.

## Basic Code Block

Use triple backticks with an optional language identifier:

<Specimen label="```lang">

````mdx
```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("World"))
```
````

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("World"))
```

</Specimen>

## Filenames and Highlighted Lines

Text after the language becomes the block's filename. Add line numbers or ranges in braces to highlight them. A filename or highlight also turns on line numbers.

<Specimen label="```lang title {lines}">

````mdx
```json dory.json {4-6}
{
  "name": "Dory",
  "logo": "./logo/logo.svg",
  "colors": {
    "primary": "#2C6BD4"
  },
  "fonts": {
    "family": "Hanken Grotesk"
  }
}
```
````

```json dory.json {4-6}
{
  "name": "Dory",
  "logo": "./logo/logo.svg",
  "colors": {
    "primary": "#2C6BD4"
  },
  "fonts": {
    "family": "Hanken Grotesk"
  }

```

<SpecimenProps>

<Prop name="Filename" type="dory.json">Any text after the language. Shown in the header with the language.</Prop>
<Prop name='title="..."' type='title="Fetch users"'>Same as a bare filename; use it when the title contains braces or quotes.</Prop>
<Prop name="{lines}" type="{1,4-6}">Comma-separated line numbers and ranges to highlight.</Prop>

</SpecimenProps>

</Specimen>

## Diffs

Use `diff` for a plain diff, or `diff-<lang>` to keep syntax highlighting. Lines starting with `+` or `-` are marked, and the header counts them.

<Specimen label="```diff-json">

````mdx
```diff-json dory.json
  "fonts": {
-   "family": "Inter",
+   "family": "Hanken Grotesk",
    "mono": { "family": "JetBrains Mono" }
  }
```
````

```diff-json dory.json
  "fonts": {
-   "family": "Inter",
+   "family": "Hanken Grotesk",
    "mono": { "family": "JetBrains Mono" }
  }
```

</Specimen>

## Terminal Sessions

A `bash`, `sh`, `shell`, `zsh` or `console` block with `$ ` prompts renders as a terminal. The command name is highlighted and other lines are output.

<Specimen label="```sh">

````mdx
```sh
$ dory dev
✓ Compiled 48 pages in 1.2s
$ dory build
✓ Wrote 48 pages to ./dist
```
````

```sh
$ dory dev
✓ Compiled 48 pages in 1.2s
$ dory build
✓ Wrote 48 pages to ./dist
```

</Specimen>

## CodeGroup — Multi-Language Tabs

Use `<CodeGroup>` to show the same code in multiple languages. Each child code block becomes a tab, labelled by its title or language.

<Specimen label="&lt;CodeGroup&gt;">

````mdx
<CodeGroup>
  ```python
  import requests

  response = requests.get("https://api.example.com/users")
  print(response.json())
  ```
  ```javascript
  const response = await fetch("https://api.example.com/users");
  const data = await response.json();
  console.log(data);
  ```
  ```go
  resp, err := http.Get("https://api.example.com/users")
  if err != nil {
      log.Fatal(err)
  }
  defer resp.Body.Close()
  ```
</CodeGroup>
````

## HTTP Method Badges

Add `tag` and `label` to a code block inside a `CodeGroup` to show HTTP method badges:

<Specimen label="```lang tag label">

````mdx
<CodeGroup>
  ```bash tag="GET" label="/api/users"
  curl https://api.example.com/users
  ```
  ```bash tag="POST" label="/api/users"
  curl -X POST https://api.example.com/users \
    -H "Content-Type: application/json" \
    -d '{"name": "Alice"}'
  ```
</CodeGroup>
````

<CodeGroup>

</Specimen>

## Inline Code

Use single backticks for inline `code` within prose text.

```mdx
Call the `greet()` function with a `name` parameter.
```

## Copy Button

All code blocks include a **copy button** in the header. It copies the raw code to the clipboard and shows a checkmark for 1 second.
