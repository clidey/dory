# Installation

## Install the CLI

Install Dory globally to use the `dory` command anywhere:

<CodeGroup>
  ```bash npm
  npm install -g @clidey/dory
  ```
  ```bash pnpm
  pnpm add -g @clidey/dory
  ```
  ```bash yarn
  yarn global add @clidey/dory
  ```
</CodeGroup>

Verify the installation:

```bash
dory version
# Prints the installed Dory version
```

## CLI Commands

<AccordionGroup>
  <Accordion title="dory init" icon="plus">
    Creates a starter `dory.json` and `docs/introduction.mdx` in the current directory.
  </Accordion>
  <Accordion title="dory dev" icon="play">
    Starts a live preview and reloads when your documentation changes.
  </Accordion>
  <Accordion title="dory check" icon="check">
    Validates navigation, links, assets, anchors, and page metadata across the site.
  </Accordion>
  <Accordion title="dory build" icon="hammer">
    Compiles your MDX files and outputs a static site to the `dist/` directory.

    ```bash
    dory build
    ```

    This reads your `dory.json`, processes all your pages, and produces a fully static site ready to deploy.
  </Accordion>
  <Accordion title="dory preview" icon="eye">
    Serves a previously built site locally so you can review it before deploying.

    ```bash
    dory preview
    # Serving dist/ at http://localhost:3000
    ```

    <Warning>
      Run `dory build` before `dory preview`. The preview command serves the built output, not the source files.
    </Warning>
  </Accordion>
  <Accordion title="dory version" icon="info">
    Prints the installed version of Dory.

    ```bash
    dory version
    # Prints the installed Dory version
    ```
  </Accordion>
</AccordionGroup>

## Project Structure

A Dory project has this structure:

```
my-docs/
├── dory.json          # Site configuration (required)
└── docs/
    ├── logo.svg        # Starter logo
    └── introduction.mdx # Your first page
```

<Note>
  Run Dory commands from the folder containing `dory.json`. Put MDX pages and assets in `docs/`. Existing flat projects with pages beside `dory.json` still work.
</Note>
