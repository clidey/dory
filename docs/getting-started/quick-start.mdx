# Quick Start

## 1. Create a documentation project

Install the CLI, create a folder, and initialize your site:

```bash
pnpm add -g @clidey/dory
mkdir my-docs
cd my-docs
dory init
```

`dory init` creates `dory.json`, `docs/introduction.mdx`, and a starter logo. Keep your pages in `docs/` and add their page keys to `dory.json` navigation.

## 2. Write with a live preview

```bash
dory dev
```

Open the local URL shown in your terminal. Changes to your MDX files reload while you write.

## 3. Check the whole site

```bash
dory check
```

The check reports missing navigation pages, broken local links and anchors, missing assets, and invalid frontmatter. Run it in CI before publishing.

## 4. Build and preview

```bash
dory build
dory preview
```

The static site is written to `dist/`. The build accepts a top-level `docs/` folder and does not modify the installed Dory package. `dory preview` also serves the optional [documentation chat](/configuration/chat) when you configure a model on the server.
